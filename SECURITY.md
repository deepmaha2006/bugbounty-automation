# Security Policy

HydraX is an offensive security platform maintained solely by **Deepesh Mahawar**
(Cybersecurity Engineer · SOC Analyst). Security and responsible handling are
treated as first-class concerns throughout the project.

## Reporting a Vulnerability

If you identify a security weakness in this codebase, please report it
**privately** to the author rather than opening a public issue.

- **Contact:** via the author's GitHub profile — https://github.com/deepmaha2006
- Please include a clear description, affected component, and reproduction steps.
- Allow a reasonable period for triage and remediation before any disclosure.

Reports are reviewed on a best-effort basis by the author. Public disclosure of
an unpatched issue without prior coordination is discouraged.

## Scope & Authorized Use

HydraX performs **active security testing** against web targets. It must only be
run against systems that you own or for which you hold **explicit written
authorization** (e.g., an in-scope bug bounty program or a signed engagement).

Unauthorized use against third-party systems is illegal and is **not** condoned
or supported by the author. See the project `README.md` and `LICENSE` for the
full legal, ownership, and acceptable-use terms.

## Supported Versions

This is an actively developed project. Only the latest `main` branch is
maintained; prior states are not supported.
